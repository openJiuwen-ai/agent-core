# openjiuwen.auto_harness

Auto Harness Agent — A self-optimizing coding agent built on the harness framework.

This subpackage builds a self-driven coding agent on top of `openjiuwen.harness`: `AutoHarnessOrchestrator` dispatches session-level and task-level pipelines, with built-in `meta_evolve` (meta-evolution) and `extended_evolve` (extended evolution) pipelines covering stages such as assess / plan / implement / verify / commit / publish_pr / learnings / activate / merge, along with supporting infrastructure including experience store, safety rails, budget control, git worktree isolation, and CI gating.

> Note: This page provides a subpackage-level index with one-line descriptions for each class and function organized by source subpackage structure. For complete signatures, fields, methods, and examples, see the detailed subpackage documentation below. Internal types prefixed with `_` are not listed here.
