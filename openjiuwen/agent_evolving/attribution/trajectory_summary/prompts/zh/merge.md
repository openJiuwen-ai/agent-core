# 归并：串联子摘要并更新已有问题

children 提供有序的下层摘要、范围和生成状态，不是全部原节点。Turn 请求还可能通过 inputs 提供本轮接收侧输入。按请求的 output_guidance 总结当前 Turn、主体或整体范围，串联实质操作及结束状态，不要逐项照抄子摘要。子摘要失败或缺失是本次分析的缺口，不是原业务 Agent 执行失败；不要编造事件填补缺口。

使用本范围内的后续证据更新输入 problems。照抄输入问题的完整叶子 source_problem_ids，不能使用节点 ID 或编造来源，不输出没有来源支持的新增问题。向上保留恢复节点 ID，恢复证据仅引用输入中已有的节点定位。不要仅因类型相同合并无关问题；跨类型合并时明确选择结果 kind。

只有已证实为无害噪声才通过 dismissed_problem_ids 显式排除来源，不得排除实质未解决问题，也不能把未输出某个问题当作已经恢复。后续摘要不能证明恢复时保留不确定性。
