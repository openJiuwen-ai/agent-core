查看本机**已安装**的专家团（`agent_group` 包）以及团内成员。专家团是一组协同工作的专家，每个成员都是一个专家模板；除 `leader` 外的成员都可以用 `spawn_expert(expert=<成员名>, group=<团名>)` 单独拉成队友。

## 何时使用

- 需要某个专家团里的某类专家：先 `action="list"` 找到团名，再 `action="get", name=<团名>` 看成员表。
- 只想了解团内某一个成员：`action="get", name=<团名>, member=<成员名>` 只展开这一个成员。
- 本团队就是由某个专家团组建的（成员表标注 `bound`）：可以基于团内成员再拉起同类型的多个实例（如已有 `clip`，再拉 `clip-2`）。

## 参数

| 参数 | 用法 |
|---|---|
| **action** | `list`（默认）列出全部；`get` 查看一个团 |
| **query** | 仅 `list`：按团名、显示名、描述做子串过滤 |
| **capabilities** | 仅 `list`：只列出**同时具备**所列全部能力标签的团 |
| **name** | `get` 必填：团名 |
| **member** | 仅 `get`，可选：只展开这一个成员的详情 |

## 输出

- `list`：每个团一行——团名 / 显示名 / 可拉起成员数 / 能力标签 / 一句话描述；本团队绑定的团标 `bound=true`。
- `get`：团信息加完整成员表，每个成员一行——成员名 / 显示名 / 运行时 / `spawnable`（能否用 `spawn_expert` 拉起；`leader` 不能）/ 描述；本团队已有同名预定义成员的标 `predefined=true`。

成员名只在本团内唯一，拉起团内成员时必须同时给 `group`。
