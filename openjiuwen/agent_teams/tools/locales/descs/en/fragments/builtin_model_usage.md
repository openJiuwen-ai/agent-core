**Built-in models**: some CLI kinds declare the models their own login (e.g. a subscription) offers in `<builtin_model_catalog>` (see the `builtin_model` parameter). Pick one with `builtin_model`, and optionally an `effort` from that model's `efforts`, to match the member's workload — a lighter model or lower effort for routine work, a stronger model or higher effort for hard problems. Only names and efforts from the catalog are accepted; omit both to let the CLI use its own default. The choice is kept across restarts, and `set_member_model` changes it later without respawning the member.
