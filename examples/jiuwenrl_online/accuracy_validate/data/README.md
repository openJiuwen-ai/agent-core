# Accuracy Validate Data

This directory stores committed baseline reports used by JiuwenRL online
accuracy validation checks.

LoRA drift baseline files are generated by:

```bash
python examples/jiuwenrl_online/accuracy_validate/measure_lora_drift_envelope.py \
  --mode baseline \
  --runs 10 \
  --model-path /data1/lll/models/Qwen3-4B-Thinking-2507 \
  --model-name Qwen3-4B-Thinking-2507 \
  --train-gpu 6,7 \
  --work-dir /tmp/jiuwen_lora_drift_gpu
```

The generated JSON records the model name/path, fixture path, GPU drift
statistics, and suggested thresholds. It does not require historical adapter
files to be present for normal single-run validation.
